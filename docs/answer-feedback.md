# 专家回答反馈

每条完整专家回答下可选择“有帮助”或“有问题”。负面反馈必须选择问题类型，问题说明、建议答案和参考依据均可选，每项最多4000字符。反馈可以修改或撤回；同一用户对同一会话中的同一回答只保留一份有效反馈，重新生成的回答单独评价。

管理员从“回答反馈”进入汇总页面，按专家ID、评价、问题类型和提交日期筛选，查看问答快照并导出所有匹配记录为JSON。日期和时间使用服务器default_timezone，结束日期包含整天。统计使用与列表相同的过滤条件，表示有效评价数量，不表示模型准确率。

快照来自服务端历史记录，保留提问和可见回答正文，不保存thinking或工具返回。团队回答按历史中的实际发言专家归属。纯附件问题可能没有文本；导出中的会话和回答ID用于回溯。更新反馈不会覆盖原问答快照。反馈不会直接修改模型、提示词或知识库，后续使用前仍需复核。

用户只能读取、修改和撤回自己会话的反馈，管理员汇总和导出不授予代替其他用户评价的权限。为保留改进样本，删除会话或专家不会自动清除独立反馈快照；删除用户时其反馈随用户删除。

服务重启时自动应用022_answer_feedback迁移（SQLite/PostgreSQL）。部署前按既有流程备份数据库，并一并更新后端与dashboard构建产物。

## API

- GET /api/agents/{agent_id}/threads/{thread_id}/feedback：当前用户的反馈。
- PUT 同一路径：创建或更新反馈，message_id和评价内容由JSON请求体传入。
- DELETE 同一路径：通过message_id查询参数撤回。
- GET /api/admin/feedback：分页、过滤与汇总。
- GET /api/admin/feedback/export：导出全部匹配记录，不按页面截断。

启用 enable_api_docs（或 OCTOP_ENABLE_API_DOCS=true）后，类型与参数见 /api/docs。
